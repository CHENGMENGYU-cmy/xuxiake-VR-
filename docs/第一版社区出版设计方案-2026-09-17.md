# 徐霞客社区第一版出版设计方案

日期：2026-09-17

## 一、第一版目标

第一版社区要围绕徐霞客项目的核心链路展开：

App/智能眼镜上传素材 → 素材库 → 生成/编辑日记 → 生成/编辑游记 → 发布到社区 → 首页、社区页、个人主页浏览互动。

第一版不把“随笔”和“VR内容”作为公开帖子分类入口。VR内容先作为素材或媒体属性存在，随笔后续作为扩展能力再评估。

## 二、第一版公开内容分类

涉及帖子展示和筛选的页面统一使用三个分类：

- 全部
- 日记
- 游记

其中：

- 全部：展示已公开的日记和游记。
- 日记：展示内容级别为 DIARY 的公开内容。
- 游记：展示内容级别为 TRAVELOGUE 的公开内容；历史兼容内容如果被归入游记，也应按游记规则展示。

## 三、左侧菜单栏设计

左侧菜单栏暂时不做大改，保持主结构清晰：

- 首页
- 发现
- 素材库
- 我的日记
- 我的游记
- 消息
- 通知
- 设置

分类变化主要发生在页面内部的帖子筛选栏，不把“随笔”和“VR内容”放进第一版公开社区分类。

## 四、需要统一的页面

第一版涉及帖子分类展示的页面需要保持一致：

1. 首页信息流
   - 分类：全部 / 日记 / 游记
   - 展示公开日记和公开游记

2. 社区主页
   - 分类：全部 / 日记 / 游记
   - 展示发布到该社区的公开日记和游记
   - 不再强调普通动态发布入口

3. 用户个人主页
   - 分类：全部 / 日记 / 游记
   - 展示该用户已公开的日记和游记

4. 搜索/发现结果
   - 优先围绕日记、游记、素材目的地、用户、社区进行检索
   - 不把随笔和VR作为第一版核心分类

## 五、核心发布链路

第一版要重点打通以下闭环：

1. App/智能眼镜上传数据
2. 后端同步为素材
3. 素材进入素材库
4. 素材生成或关联日记
5. 日记生成或关联游记
6. 日记/游记可以发布到社区
7. 发布后能在首页、社区主页、个人主页看到
8. 可以进行点赞、评论、收藏或基础互动

## 六、当前建议删除或隐藏的内容

第一版建议删除或隐藏：

- 首页分类里的“随笔”
- 首页分类里的“VR内容”
- 社区主页里直接发布普通动态的强入口
- 与第一版核心链路无关的随笔/VR演示种子数据入口

保留但暂不突出：

- VR素材元数据
- 兼容旧数据的字段和迁移逻辑
- 后续扩展随笔的可能性

## 七、第一阶段实施顺序

第一步：检查并修正“日记/游记发布到社区”的真实链路。

具体看：

- 日记详情页是否有发布到社区的入口
- 游记详情页是否有发布到社区的入口
- 发布时是否能选择社区
- 发布后是否写入统一帖子数据
- 发布后是否出现在首页信息流
- 发布后是否出现在对应社区主页
- 发布后是否出现在用户个人主页
- 点赞、评论、收藏等基础互动是否能对新发布内容生效

第二步：补齐缺口。

如果发现入口没有、数据没写对、页面不展示、互动失效，就逐项修正。

第三步：做一轮首版验收。

用一条真实链路验证：上传素材 → 日记 → 游记 → 发布社区 → 首页/社区/个人主页可见 → 可评论点赞。

## 八、第一版验收标准

第一版可以出版的最低标准：

- 用户能从素材生成日记
- 用户能从日记生成或整理游记
- 日记和游记都能发布到社区
- 首页、社区主页、个人主页分类一致
- 分类只有全部、日记、游记
- 新发布内容能被浏览、评论、点赞
- 旧的随笔/VR分类不会干扰主流程
