## 四、核心演示流程（建议演示顺序）

### ① 首页浏览
登录 zhangshan → 首页信息流 → 切换"发现/关注" → 类型筛选（日记/游记/VR内容）

### ② 素材库（三级链条第一层）
侧边栏"素材库" → 按天/地点/行程浏览闪拍素材（照片墙）

### ③ AI 写日记（核心亮点）
素材库 → 多选闪拍 → "AI写日记" → 选择风格（温柔治愈/生活碎片等）→ 真实 DeepSeek 生成日记 → 我的日记查看

### ④ AI 生成游记（核心亮点）
素材库/日记 → "生成游记" → 选语气/篇幅 → 结构化章节式游记自动生成（按天分章+配图+信息卡）→ 编辑器二次修改 → 发布

### ⑤ 发布与可见性
日记/游记 → 保存为私密 或 发布到社区 → 首页/发现页可见 → 地点精度控制

### ⑥ 社群
发现页"找搭子"+"推荐社群" → 加入社群 → 社群空间（动态/公告/挑战/成员）→ 发起挑战/看排行榜

### ⑦ 消息（实时 WebSocket）
张三 ↔ 赵六 发消息 → 刷新另一账号看实时到达 → 发送图片/文件

### ⑧ 管理员能力
用 xuxiake 账号登录 → 管理中心：审核队列、举报管理、用户管理
