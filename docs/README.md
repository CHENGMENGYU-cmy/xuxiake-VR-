## 新增文档放哪里

| 文档类型 | 放入 |
|---|---|
| AI 接力说明、开发交接记录、演示指引 | `00-入口与交接/` |
| 需求说明书、设计方案、内容链条、改动清单 | `10-产品与设计/` |
| 对外汇报、阶段总结（含 `.docx`） | `20-汇报材料/` |
| 首发计划、验收记录、问题清单、发布判断 | `30-首发与验收/` |
| 脚本产出的测试证据 `.json` | `40-链路证据/` |

### 命名约定

- 带日期的记录类文档统一用 `主题-YYYY-MM-DD.md`，便于按时间排序。
- 无日期的稳定文档（需求说明书、实现说明）保持原名，不加日期。

### 引用路径约定

文档已分层，跨目录引用**必须写相对当前文件的路径**，并随文档所在位置调整层级：

   同目录文件        直接写文件名
   引用其他分类      ../ 加分类目录名，再加文件名
   引用根目录文件    按层级补 ../

例如本索引（位于 docs 根）引用根目录时用 [README.md](../README.md)；
而 `00-入口与交接/` 内的文档要引用同一个文件，则需写成两层（`../../` 开头）。

**不要**写成以仓库根为起点的路径（docs 开头的那种）——在 docs 内部解析不到。
