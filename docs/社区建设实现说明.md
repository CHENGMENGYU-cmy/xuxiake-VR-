## 三、四层内容体系实现

### 3.1 数据模型

```sql
-- posts 表新增字段
ALTER TABLE posts
  ADD COLUMN content_level ENUM('SNAPSHOT','CLASSIFIED','DIARY','ESSAY')
    NOT NULL DEFAULT 'SNAPSHOT' COMMENT '内容层级',
  ADD COLUMN parent_post_id VARCHAR(36) NULL COMMENT '上级内容ID';

-- content_level 说明：
-- SNAPSHOT   ① 瞬间捕获：眼镜/手机的原始第一视角画面
-- CLASSIFIED ② 内容分类：按地点/时间/类型自动归类，不带主观色彩
-- DIARY      ③ 日记/日志：内容+部分感想，带有个人色彩但未形成正式文章
-- ESSAY      ④ 游记散文：基于前三层，有个人情感的正式文章

-- parent_post_id：自引用外键，形成内容升级链路
-- 例如：SNAPSHOT(原始照片) → DIARY(带感想的日记) → ESSAY(正式游记)
```

### 3.2 后端API

#### 内容层级查询
```
GET /api/posts/hierarchy?level=SNAPSHOT&userId=xxx&cursor=yyy&limit=12
```
按内容层级获取帖子列表，支持游标分页。

#### 分类维度聚合
```
GET /api/posts/classified/dimensions?userId=xxx
```
返回三维度分类数据：
- **byLocation**: 按地点分组统计（如"黄山 15条"）
- **byType**: 按媒体类型分组统计（VR_MEDIA/IMAGE/AUDIO等）
- **byTime**: 按月份分组统计

#### 内容层级提升
```
POST /api/posts/:id/promote
Body: { targetLevel: 'ESSAY', content: '...', title: '我的黄山游记' }
```
将内容从当前层级提升到目标层级，自动创建新记录并通过 `parent_post_id` 关联上级内容。提升到 ESSAY 级别时自动创建 Journey 记录。

### 3.3 前端页面

#### ① 瞬间捕获 (`/media`)
- 第一视角原始画面展示（照片/视频瀑布流）
- 按媒体类型筛选：全部 / 第一视角 / 瞬间捕获 / 语音记录
- VR全景内容独立标记
- 热门创作者推荐

#### ② 内容分类 (`/classified`) — 新建

- 卡片网格展示分类结果，点击进入该分类内容列表
- 描述文案："自动按地点、类型、时间整理您的瞬间捕获，不带主观色彩"

#### ③ 日记 (`/diaries`) — 新建
- 个人随笔空间，带有私密感设计
- 描述文案："内容加上部分感想情绪，带有个人色彩但未形成正式文章"

#### ④ 游记散文 (`/journeys`)

## 四、搭子匹配系统实现

### 4.1 匹配算法

```
综合得分 = 目的地匹配(≤40分) + 兴趣重合(≤25分) + 同城(15分) + 共同好友(≤10分) + 近期活跃(5分)
推荐阈值: ≥ 50分
```

| 维度 | 得分规则 | 最高分 |
|---|---|---|
| 相同目的地 | 每共享一个目的地 +20分 | 40分 |
| 共同兴趣标签 | 每重合一个标签 +8分 | 25分 |
| 同城 | 区域完全相同 +15分 | 15分 |
| 共同好友关注 | 每位共同好友 +5分 | 10分 |
| 近期活跃 | 近期发布≥3条内容 +5分 | 5分 |

### 4.2 后端API

```
GET /api/social/recommended/companions?destination=黄山&page=1&limit=20
```

请求流程：
1. 获取当前用户兴趣标签和已访问目的地
2. 排除本人和已关注用户
3. 并行获取候选用户：兴趣标签、共同好友、目的地交集
4. 应用多维评分算法
5. 过滤低于50分的候选人
6. 按得分降序分页返回

返回字段：`matchScore`、`matchReasons`（匹配原因中文描述）、`sharedDestinations`（共享目的地列表）、`commonTags`（共同标签）

### 4.3 前端页面

**找搭子页** (`/discover` → 默认Tab)

- 目的地搜索筛选
- 搭子卡片展示：
  - 头像 + 昵称 + 匹配度百分比
  - 匹配原因标签（去过XX / N个共同兴趣 / 同城 / 共同好友）
  - 共享目的地标签
  - 操作按钮：关注 / 打招呼（快捷私信）
