# 真实图片资产恢复说明（2026-09-16）

本项目的运行时上传目录 `server/uploads/` 被 `.gitignore` 忽略，不能依赖它随普通代码克隆交付。为了让真实地点图片在新环境可恢复，真实封面资产已复制到可版本化目录：

- 资产源目录：`server/assets/real-covers/`
- 运行时目标目录：`server/uploads/real-covers/`
- 来源清单：`server/assets/real-covers/ATTRIBUTION.json`
- 校验清单：`server/assets/real-covers/manifest.json`
- 恢复脚本：`server/scripts/restore-real-covers.mjs`
- 数据库引用迁移：`server/sql/apply-real-community-images-2026-09-11.sql`

## 资产内容

当前资产包包含 17 张真实地点图片，合计约 4.2 MB。每张图在 `manifest.json` 中记录：

- 文件名
- 应用内访问路径 `/uploads/real-covers/*.jpg`
- 来源页面和来源图片 URL
- 文件大小
- SHA256 校验值

## 新环境恢复步骤

在仓库根目录执行：

```powershell
node server/scripts/restore-real-covers.mjs --check
node server/scripts/restore-real-covers.mjs --copy
```

第一条命令只校验 `server/assets/real-covers/` 中的可交付资产是否完整；第二条命令把资产复制到 `server/uploads/real-covers/`。如果目标目录已经有同名文件，默认跳过；需要覆盖时使用：

```powershell
node server/scripts/restore-real-covers.mjs --copy --force
```

然后对数据库执行：

```sql
source server/sql/apply-real-community-images-2026-09-11.sql;
```

这条 SQL 会把原本指向 `/uploads/demo-covers/*.jpg` 的社群头像、社群封面、帖子媒体图和 `vr_metadata.image` 替换成 `/uploads/real-covers/*.jpg`。

## 验收方式

1. 文件层验收：

```powershell
node server/scripts/restore-real-covers.mjs --check
```

返回 `ok: true` 且 `fileCount: 17`。

2. 服务层抽查：启动后端和前端后，访问任意真实图：

```text
http://localhost:3001/uploads/real-covers/lijiang.jpg
http://localhost:3000/uploads/real-covers/lijiang.jpg
```

两者都应返回图片；3000 端口依赖前端 rewrite 代理到后端。

3. 数据层验收：数据库中不应再有 demo-covers 图片引用。

```sql
SELECT 'communities_avatar_demo' AS item, COUNT(*) AS count
FROM communities
WHERE avatar_url LIKE '/uploads/demo-covers/%'
UNION ALL
SELECT 'communities_cover_demo', COUNT(*)
FROM communities
WHERE cover_url LIKE '/uploads/demo-covers/%'
UNION ALL
SELECT 'media_items_url_demo', COUNT(*)
FROM media_items
WHERE url LIKE '/uploads/demo-covers/%' OR thumbnail_url LIKE '/uploads/demo-covers/%'
UNION ALL
SELECT 'posts_meta_image_demo', COUNT(*)
FROM posts
WHERE JSON_VALID(vr_metadata)
  AND JSON_UNQUOTE(JSON_EXTRACT(vr_metadata, '$.image')) LIKE '/uploads/demo-covers/%';
```

以上 count 应为 0。

## 注意

- `server/uploads/real-covers/` 是运行时目录，可以删除后由脚本恢复。
- `server/assets/real-covers/` 是可交付资产源，不应在没有替代资产和来源清单的情况下删除。
- 新用户默认头像已改为 `/api/placeholder/{username}`，不依赖这些图片资产。
