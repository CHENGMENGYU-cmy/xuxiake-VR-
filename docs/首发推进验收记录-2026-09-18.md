## 已完成改动

- 登录页的短信、微信、支付宝入口，以及注册页的手机入口明确标记为暂未开放并禁止点击；账号密码和邮箱注册保留。
- 短信接口默认拒绝模拟发送及校验，实际 HTTP 抽查返回 503 和未开放说明。仅非生产环境显式设置 `ALLOW_DEV_SMS=true` 可启用开发模拟；生产环境始终拒绝该模拟开关。
- `PostsController` 统一通过 `requireActiveAccessToken` 检查账号当前状态。封禁、注销或已删除账号持有旧令牌也无法通过该控制器执行写操作；可选认证的公开浏览按游客处理。
- 移除生产构建对 Google 字体下载的依赖，使用中英文系统字体栈。不同设备字体外观可能略有差异。
- 当前 Windows 环境 Turbopack 在字体问题解决后仍出现 CSS 子进程连接中断；已使用 Next.js 支持的 Webpack 构建成功，并将 `web/package.json` 的 build 固定为 `next build --webpack`。
- 根目录 `npm start` 的前端改为生产启动；开发继续使用 `npm run dev`。启动生产环境前仍必须配置 `NODE_ENV=production`、生产密钥、数据库、域名与 API 地址。
- README 移除“任意密码”旧说明，说明正式支持的认证方式。
